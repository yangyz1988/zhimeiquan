# 抖音平台内容模板

> 抖音：节奏快，前 3 秒必须有钩子，时长短
> 算法偏好：完播率 > 互动率 > 关注转化率

## 一、30-60s 黄金结构

```
[0-3s]  钩子（痛点/数字/反常识）
[3-8s]  痛点共鸣（场景化）
[8-25s] 干货展开（3 个要点）
[25-35s] 反转/高潮
[35-50s] 结论总结
[50-60s] CTA（关注/评论引导）
```

## 二、5 个钩子示例

1. **数字型**："月入 5 万的副业，我只推荐这 3 个"
2. **反常识型**："你以为努力就有用？这 3 种努力都是浪费"
3. **痛点型**："加班到凌晨，发现同事靠这个月入 3 万"
4. **悬念型**："我用了 3 年才明白的 1 个道理，今天免费告诉你"
5. **对比型**："穷人和富人的差距，不是钱，是这 3 个习惯"

## 三、字幕节奏

- **每 2-3 秒换一行**字幕（保持阅读舒适度）
- 关键词用**大号/彩色/加粗**
- 数字单独成行（视觉锚点）
- 关键反差点用**对比色**字幕
- 避免一句话一行（拖慢节奏）

## 四、配乐建议

| 情绪段 | 配乐类型 |
|--------|----------|
| 钩子段 | 鼓点紧张/快节奏电子 |
| 干货段 | 轻快 BGM（不抢人声） |
| 反转段 | 静音 0.5s → 情绪 BGM |
| 收尾段 | 温暖/励志 BGM |

**避坑**：不要全程用同一首歌，会引发疲劳。

## 五、发布优化

- **时长**：首发选 30s（推流测试），爆款再追投 60s
- **封面**：大字 + 数字 + 强对比色
- **标题**：15-20 字，含数字/情绪/反常识
- **话题**：3-5 个，1 个大话题 + 2-3 个垂直话题

## ✅ 案例 vs ❌ 反例

**✅ 案例**："3 句话让老板主动加薪 50%（封面大字）" + 30s 干货 + 评论区扣 1 领话术包
**❌ 反例**："今天给大家分享一个职场经验"（封面普通 + 60s 平铺 + 无 CTA）

## 🚀 30 秒应用

```text
[抖音脚本生成]
1. 选题 → 数字+痛点
2. 钩子 → 抄 5 个示例
3. 结构 → 30s 黄金 6 段
4. 字幕 → 每 2-3 秒换行
5. 配乐 → 选 2 段拼接
6. CTA → 评论区扣 1
```

## 六、平台算法数据（知识库补充）

| 核心指标 | 冷启动合格线 | 推流线 | 算法意义 |
|:---------|:-----------:|:------:|:---------|
| 2秒完播率 | >70% | - | 决定初始推荐 |
| 15秒完播率 | >45% | >35% | 最高权重 |
| 点赞率 | >3% | >3% | 情绪共鸣 |
| 评论率 | >0.5% | >0.3% | 推流核心 |
| 粉丝占比 | <20% | <30% | 越低越破圈 |

- **冷启动窗口**：1-3小时，黄金时间内完播率决定生死
- **新号养号**：前7条是关键，建议养号3-7天再发
- **前5字**：决定两秒完播率，前5字必出钩子
- **发布时段**：工作日12:00-13:30/18:00-20:00/21:00-23:00，周末10:00-12:00/20:00-23:00
- **封面**：9:16竖版，大字报+高对比色+人物表情
- **标题**：前5字钩子，≤15字最优，含数字或反常识
- **标题字数**：≤55字（平台限制），最优15字以内

## 七、爆款公式适配

**抖音版爆款 = 身份锚定 x 情绪引爆 x 好奇心缺口 x 价值交付**
- 前3秒必须出现身份锚+情绪钩子
- 每10秒一个情绪钩子（反转/金句/节奏变化）
- DOU+策略：发布后30分钟播放<500立即投100元达人相似粉丝
