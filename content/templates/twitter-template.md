# X (Twitter) 爆款模板（Fire Score · 13 平台）

> X 是实时 + 观点驱动，**情绪值+独特观点**权重最高，长文 Thread 是涨粉神器。

## 一、平台特点

- **用户画像**：25-45 岁，全球科技/政治/财经/创作者密度高
- **流量逻辑**：For You + Following 双源；**RT 率**和**引用推**是关键
- **风格基调**：犀利、有观点、可暴论；段子+洞察
- **标题规则**：1-12 词（主推文），Thread 后续每条 1 个观点
- **关键指标**：Impression / 互动率 / Bookmark / Profile 点击

## 二、爆款结构（主推文 / Thread）

### 单推（≤280 字符）

| 部分 | 字数 | 任务 |
|:-----|:----:|:-----|
| 钩子 | 1-50 | 反常识 / 暴论 / 数据 |
| 论据 | 50-200 | 1-3 句支撑 |
| CTA | 200-280 | "RT if useful" |

### Thread（5-12 条）

- **第 1 条**：最强结论 + 钩子 + "🧵"
- **第 2-10 条**：每条 1 个论点 + 1 张图/数据
- **最后 1 条**：总结 + 关注引导

## 三、钩子句式（10 个 / 英文）

1. `Unpopular opinion: [hot take]`
2. `[Number] [things] about [topic] nobody talks about`
3. `I spent [time] studying [topic]. Here's what I learned:`
4. `The biggest [topic] mistake I see [audience] making:`
5. `[Industry] is dead. Here's what's next:`
6. `If you're [action], stop. Do this instead:`
7. `[Hot take] on [trend]:`
8. `[Number] signs you're [good at thing]:`
9. `Read this if you [struggle]:`
10. `The [topic] cheat sheet:`

## 四、互动技巧

- **Quote RT 自己**：补充资料，激活算法
- **回复自己**：用 2 号账号（合规模拟）提尖锐问题
- **同主题连发**：1 小时内连发 3-5 条，触发"创作者模式"
- **时间**：UTC 时间配合目标时区（美东 8-10am / 欧 7-9pm / 亚 9-11pm）

## 五、Thread 结构模板

```text
Tweet 1/🧵: [最强结论 + 钩子]
Tweet 2: [支撑数据 1]
Tweet 3: [支撑数据 2]
Tweet 4: [反例]
Tweet 5: [我的做法]
Tweet 6: [结果]
Tweet 7: [可复用的方法论]
Tweet 8/n: [总结 + 关注引导]
```

## ✅ 案例 vs ❌ 反例

**✅ 案例**：I studied 100 viral threads. Here are the 5 patterns（数据+好奇+Thread）— Fire Score 预估 91
**❌ 反例**：Having a great day everyone（无观点、无钩子）— Fire Score 预估 25

## 🚀 30 秒应用

```text
1. 平台 → X
2. 钩子 → "Unpopular opinion" / "[N] things nobody talks about"
3. Thread → 5-10 条结构
4. 时间 → 美东 8-10am
5. 互动 → 1 小时内自 Quote 1-2 次
6. CTA → "Bookmark this"
```

## 七、爆款公式适配

**Twitter版爆款 = 观点锐度 x 数据洞察 x 金句传播**

- Thread结构：结论→数据→反例→方法论→总结
- 暴论之后必有3段论据支撑
- 互动引导："RT if useful" / "Bookmark this"
