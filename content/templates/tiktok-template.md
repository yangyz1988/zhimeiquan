# TikTok 平台内容模板

> TikTok：全球化，趋势敏感
> 算法偏好：完播率 > 分享率 > 评论率 > 关注率

## 一、跨文化钩子

### 普世情感钩子（跨文化友好）

1. **好奇心**：`Wait for it...` / `You won't believe this`
2. **反差感**：`POV: When [A] meets [B]`
3. **实用感**：`Life hack: [X]`
4. **悬念感**：`Things they don't tell you about [X]`
5. **共鸣感**：`Tell me you [X] without telling me`

### 文化敏感红线

- 避免种族/宗教/政治话题
- 避免手势歧义（OK 手势在某些国家冒犯）
- 避免本地化梗（其他国家看不懂）
- 避免血腥/暴力/成人内容

## 二、环球趋势适配

### 3 大环球趋势类型

| 趋势类型 | 适配方法 |
|----------|----------|
| 音频趋势 | 48 小时内跟拍，蹭原声流量 |
| 挑战趋势 | 简化挑战门槛，鼓励 UGC |
| 格式趋势 | 复用框架（前后对比/绿幕特效/口播） |

### 趋势发现渠道

- **For You Page**：刷 30 分钟找 3-5 个新趋势
- **Discover 页面**：查看每日热榜
- **创作者工具**：TikTok Creative Center 官方趋势
- **跨平台对照**：IG Reels / YouTube Shorts 同款内容

## 三、字幕多语种

### 字幕策略

- **原音 + 字幕**：保持原音，加 2-3 种语言字幕
- **画中画字幕**：用大字号居中显示
- **动态翻译**：用 CapCut 等工具加多语言字幕
- **关键词双语**：在画面上加中英/西英对照关键词

### 字幕颜色规则

- 黑色背景 + 白色文字（高对比）
- 关键词用黄色/红色（强化）
- 避免超过 2 种颜色（视觉干扰）

## 四、视频结构（15-60 秒）

```
[0-1s]  视觉冲击（不要开场白）
[1-3s]  钩子（核心问题/反差）
[3-15s] 第一段内容
[15-30s] 反转/高潮
[30-45s] 结论/CTA
[45-60s] 互动引导（评论/合拍）
```

## 五、TikTok 特色功能

- **Duet（合拍）**：设计"可合拍"内容（留空白位置）
- **Stitch（拼接）**：热门视频开头 + 你的反转
- **绿幕特效**：用绿幕加背景/素材
- **声音选择**：用 TikTok 音乐库的热曲
- **特效贴纸**：加 1-2 个增强趣味

## 六、发布优化

| 维度 | 建议 |
|------|------|
| 时长 | 首发 15s（测试），爆款追投 30-60s |
| 封面 | 第 1 帧 = 最强瞬间 |
| 标签 | 3-5 个：1 大类 + 2 中类 + 2 长尾 |
| 发布时间 | 美国东部时间 7-9am / 7-9pm |
| 频率 | 每天 1-3 条（养号期） |

## ✅ 案例 vs ❌ 反例

**✅ 案例**：15s 强反转 + 英文钩子 + 热门音频 + 双语字幕 + Duet 友好设计
**❌ 反例**：60s 慢节奏 + 中文口播 + 无字幕 + 无特效

## 🚀 30 秒应用

```text
[TikTok 脚本生成]
1. 钩子 → 选 5 个普世情感中 1 个
2. 视觉 → 第 1 帧最强瞬间
3. 节奏 → 15-30s 完成反转
4. 字幕 → 英文+本地语言双行
5. 趋势 → 跟 1 个热门音频/挑战
6. 互动 → 设计可 Duet/Stitch
```

## 七、平台算法数据（知识库补充）

| 核心指标 | 合格线 | 算法意义 |
|:---------|:-----:|:---------|
| 完播率 | >40% | 最高权重 |
| 分享率 | >0.5% | 病毒传播指标 |
| 评论率 | >0.5% | 社区互动 |
| 关注率 | >1% | 账号增长 |

- **流量逻辑**：For You算法分发+趋势跟随
- **冷启动**：推荐极快，1小时内判断内容质量
- **发布时段**：美国东部时间7-9am/7-9pm，按目标市场时区调整
- **时长**：首发15s（测试），爆款追投30-60s
- **封面**：第1帧=最强瞬间，不做额外封面
- **标签**：3-5个，1大类+2中类+2长尾
- **频率**：每天1-3条（养号期）
- **趋势发现**：刷FYP 30分钟找3-5个新趋势

## 八、爆款公式适配

**TikTok版爆款 = 视觉冲击 x 趋势跟随 x 音乐卡点**
- 前1秒视觉冲击（不要开场白）
- 15-30秒内完成反转
- 双语字幕（英文+本地语言）
- 设计可Duet/Stitch的内容（留空白位置）
- 趋势类型：音频趋势（48h内跟拍）、挑战趋势（简化门槛）、格式趋势（复用框架）
