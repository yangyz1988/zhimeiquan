# YouTube 平台内容模板

> YouTube：国际化视角，SEO 友好
> 算法偏好：点击率（CTR）> 观看时长（Watch Time）> 互动率

## 一、SEO 标题

### 公式：`[核心关键词]+[数字/年份]+[利益点]+[情绪]`

### 5 种模板

1. **How to**：`How to [X] in 2026 (Step-by-Step Guide)`
2. **数字型**：`7 [X] Tools That Will Change Your Life in 2026`
3. **对比型**：`I Tried [X] for 30 Days — Here's What Happened`
4. **反常识型**：`Stop Doing [X] — Do This Instead`
5. **教程型**：`The Complete [X] Tutorial for Beginners (2026)`

**长度建议**：50-60 字符（搜索结果完整显示）

## 二、缩略图 CTR 法则

| 元素 | 标准 |
|------|------|
| 主文字 | 3-5 个单词，大字体 |
| 表情 | 1-2 个强化情绪（震惊/思考/兴奋） |
| 颜色 | 高对比（黄/红/橙 vs 深色背景） |
| 人物 | 放大面部表情（眼睛+嘴型） |
| 分辨率 | 1280×720 像素 |
| 测试 | A/B 测试 2-3 个版本 |

**目标 CTR**：8-12%（优秀），12%+（爆款）

## 三、章节时间戳

```markdown
0:00 - 介绍
1:23 - 第一个方法
4:56 - 实操演示
8:12 - 进阶技巧
12:30 - 常见错误
15:45 - 总结
```

### 时间戳使用规则

- 第一章 1:00 之后（让观众先进来）
- 章节长度 2-5 分钟
- 章节标题用名词/动词开头
- 添加到描述区（自动生成 YouTube 章节）

## 四、视频结构（10-20 分钟）

```
[0-30s]  Hook（钩子 + 价值预告）
[30-60s] 上下文铺垫
[1-3min] 第一核心内容
[3-8min] 第二核心内容
[8-14min] 第三核心内容 + 案例
[14-18min] 高级技巧/常见错误
[18-20min] 总结 + CTA（订阅/评论）
```

## 五、SEO 描述模板

```markdown
[前 2 行] 视频核心内容 + 关键词
[中间] 时间戳 + 资源链接
[末尾] 相关视频 + 订阅引导 + 社交媒体
```

### 标签策略

- **5-8 个标签**：1 个大词 + 3 个中词 + 3 个长尾词
- **避免堆砌**：YouTube 已弱化标签权重
- **借势**：蹭热点标签（带年份/事件）

## 六、国际化适配

- **口音**：避免地方口音，标准美音/英音优先
- **字幕**：必加英文字幕（影响海外流量）
- **多语言**：上传 SRT 文件覆盖主要语言
- **文化**：避免地域梗/方言/只在本地流行的梗

## ✅ 案例 vs ❌ 反例

**✅ 案例**：`7 AI Tools That Will Replace Your Job in 2026` + 高对比缩略图 + 完整章节 + SEO 描述
**❌ 反例**：`My thoughts on AI`（无关键词、无钩子、无章节、无描述优化）

## 🚀 30 秒应用

