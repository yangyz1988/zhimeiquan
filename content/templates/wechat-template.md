# 微信公众号内容模板

> 公众号：深度长文，逻辑清晰
> 算法偏好：阅读完成率 > 在看/点赞 > 转发率 > 关注转化

## 一、标题 26 字法则

- **不超 26 字**（手机屏显示完整）
- **前 13 字必须抓人**（前 13 字决定打开率）
- **含 1 个数字 / 1 个反差点**
- **避免标题党**（打开后与标题不符会拉低完成率）

### 5 种标题模板

1. **数字型**：`我用 3 年时间，验证了这 5 个真相`
2. **反常识型**：`越是普通的人，越容易做出不普通的事`
3. **悬念型**：`那个 35 岁被裁员的同事，后来怎么样了`
4. **对比型**：`月入 5 千和月入 5 万的人，差距真的不是钱`
5. **观点型**：`我劝你不要轻易做自媒体`

## 二、开头 3 段定调

```
[第 1 段] 钩子（场景/痛点/反常识）
[第 2 段] 共鸣（"你是否也..."）
[第 3 段] 价值预告（"今天讲 3 件事"）
```

开头 200 字决定"是否继续读"，必须在前 3 段内交付价值预告。

## 三、阅读完成率优化

| 因素 | 优化策略 |
|------|----------|
| 长度 | 2000-3000 字最佳（阅读完成率 60%+） |
| 段落 | 3-5 行换段，移动端友好 |
| 小标题 | 每 500 字加 1 个 H2 标题 |
| 配图 | 每 800-1000 字 1 张图 |
| 重点 | 关键句加粗/换色 |
| 节奏 | 长短句交替，避免大段文字 |

## 四、文章结构模板

```markdown
# [标题]

[开头 3 段：钩子+共鸣+预告]

## 一、[第一个观点]
[展开 3-5 段 + 案例/数据]

## 二、[第二个观点]
[展开 3-5 段 + 案例/数据]

## 三、[第三个观点]
[展开 3-5 段 + 案例/数据]

## 写在最后
[总结 + 行动号召 + 互动引导]
```

## 五、互动引导位置

- **文中**：第 2/3 个小标题后插入"看到这里点个在看"
- **结尾**："留言区聊聊你的看法"
- **菜单栏**：常驻 3 个入口（精华合集/加群/合作）
- **关注引导**："关注我，每周更新 [选题方向]"

## 六、视觉与排版

- 强调色：1-2 个，全文统一
- 字号：正文 16-17px，重点 18-20px
- 行距：1.75-2.0（移动端阅读舒适）
- 配图风格：与账号调性统一

## ✅ 案例 vs ❌ 反例

**✅ 案例**：2000 字 + 3 个小标题 + 5 张配图 + 2 个互动引导 + 26 字内标题
**❌ 反例**：5000 字 + 无小标题 + 0 张图 + 无互动 + 30 字标题

## 🚀 30 秒应用

```text
[公众号文章生成]
1. 标题 → 26 字内 + 数字/反常识
2. 开头 3 段 → 钩子+共鸣+预告
3. 正文 → 2000-3000 字 + 3 个 H2
4. 配图 → 每 800-1000 字 1 张
5. 互动 → 文中 1 个 + 结尾 1 个
```
