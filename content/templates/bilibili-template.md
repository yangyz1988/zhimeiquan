# B 站平台内容模板

> B 站：深度内容，可以长视频
> 算法偏好：完播率 > 三连率 > 评论深度 > 投币率

## 一、长视频结构（8-15 分钟）

```
[0-30s]  片头：核心钩子 + 价值预告
[30-60s] 自我介绍 + 内容地图（章节预览）
[1-3min] 第一段干货（铺垫）
[3-6min] 第二段干货（核心）
[6-9min] 第三段干货（进阶）
[9-12min] 案例/实操演示
[12-14min] 总结 + 互动彩蛋
[14-15min] 片尾 + 三连引导
```

## 二、章节标记（必做）

```markdown
00:00 开场钩子
00:30 自我介绍
01:15 第一个误区
03:40 实操演示
07:20 进阶玩法
12:00 总结彩蛋
14:30 下期预告
```

- 章节标题用"动词 + 利益点"
- 至少 3 个章节，否则不显示进度条
- 每个章节 1-3 分钟，最长不超过 5 分钟

## 三、片头 5 秒定则

- **第 1 秒**：画面/声音冲击
- **第 2-3 秒**：核心钩子（"今天讲透 XX 的 3 个秘密"）
- **第 4-5 秒**：价值预告（"看完你能 [具体收益]"）

**避坑**：不要 BGM 起手 + logo 动画 + 自我介绍（=劝退率 +60%）

## 四、互动彩蛋 5 种

1. **进度条彩蛋**：每 25%/50%/75% 弹小贴士
2. **关键词彩蛋**：评论特定关键词触发回复
3. **二周目彩蛋**：片尾放 1 张隐藏截图，引导重看
4. **彩蛋评论区**：UP 主自己置顶隐藏问题
5. **三连奖励**：明说"三连后告诉你下期主题"

## 五、人设语言

- **学术派**：用"我们今天来研究一下..."
- **实战派**：用"我实操给你看..."
- **陪伴派**：用"兄弟们，我回来啦..."
- **吐槽派**：用"这事儿我必须得说说..."

> B 站用户对"装"很敏感，选 1 个真实人设深耕。

## 六、投币/收藏触发点

- 干货密度高（信息量大 → 收藏）
- 真诚表达（情绪真实 → 投币）
- 强观点输出（立场鲜明 → 评论）
- 系列化内容（连续追更 → 关注）

## ✅ 案例 vs ❌ 反例

**✅ 案例**：3 分钟钩子 + 12 分钟干货 + 章节标记 + 进度条彩蛋 + 三连引导
**❌ 反例**：1 分钟片头 + 8 分钟平铺干货 + 无章节 + 无互动

## 🚀 30 秒应用

```text

2. 章节 → 至少 3 个，1-3 分钟 1 个

4. 干货 → 分 3 段，层层递进

```
