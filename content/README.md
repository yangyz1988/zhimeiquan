# 内容知识库

## 目录结构

- `methodology/` - 方法论体系（10个维度）
  - `01-hook-power.md` - 钩子力方法论（Fire Score 维度1）
  - `02-trust.md` - 信任度方法论（Fire Score 维度2）
  - `03-retention.md` - 完播力方法论（Fire Score 维度3）
  - `04-conversion.md` - 转化力方法论（Fire Score 维度4）
  - `05-emotion.md` - 情绪值方法论（Fire Score 维度5）
  - `06-viral-formula.md` - 爆款公式与核心方法（底层公式+分级方法）
  - `07-platform-algorithm.md` - 平台算法与核心指标（13平台数据表）
  - `08-100percent-system.md` - 100%爆款保障系统（6层确定性控制）
  - `09-comment-operations.md` - 评论区运营与冷启动SOP
  - `10-publishing-guide.md` - 视觉音频与发布优化指南

- `templates/` - 13平台模板库（含算法数据）
  - 抖音/快手/小红书/B站/视频号/公众号/微博/知乎
  - TikTok/Instagram/YouTube/Twitter_X/LinkedIn
  - 每个模板包含平台特定爆款公式+核心指标+发布时段+封面规格

- `experts/` - 专家资源库
  - `expert-persona.md` - 专家型人设
  - `mentor-persona.md` - 学长型人设
  - `sister-persona.md` - 姐妹型人设
  - `README.md` - 50+精选专家智能体资源库

- `prompts/` - 提示词库（新增）
  - `prompt-library.md` - 212条完整提示词（8大分类）
  - `title-generator-prompt.md` - 爆款标题生成器v3.1
  - `viral-generator-prompt.md` - 爆款方法论生成器v4.0

## 数据来源

- 180+全球头部号拆解（抖音/快手/小红书/微博/B站/知乎/视频号/公众号/TikTok/Instagram/YouTube/Twitter/LinkedIn）
- 平台算法白皮书+官方创作者中心
- 实战派导师爆款方法论
- 拓界AI 212条提示词库

## 使用方式

Python 服务会读取本目录下的知识库文件，用于 AI 生成时的上下文参考。
单条目建议≤800字符以适配 content_loader 限制。
