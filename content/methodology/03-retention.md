# 完播力方法论（Fire Score 维度 3 · 权重 20%）

> 完播力决定用户是否看完，是算法推荐的核心指标之一。

## 一、节奏控制 3 原则

- **快进原则**：每 3-5 秒必须有新信息/新画面
- **卡点原则**：在用户最容易划走的 8 秒/15 秒/25 秒设置小高潮
- **降速原则**：核心信息/情绪高点放慢 0.5 倍速

## 二、转折点设计公式

```
[开场钩子] → [认同建立] → [第一次反转] → [认同加深] →
[第二次反转] → [核心结论] → [行动号召]
```

每个视频至少 **2 个转折点**，转折点 = 信息增量 + 情绪变化

## 三、循环结构（防流失利器）

- **句首预支**：在段尾预告下段开头（"接下来这条更炸..."）
- **段落回扣**：每隔 30 秒回扣一次核心主题
- **结尾回环**：结尾回到开头的话题/画面，形成闭环

## 四、信息密度曲线

| 时间段 | 密度 | 用途 |
|--------|------|------|
| 0-3 秒 | 极高 | 钩子/利益点 |
| 3-10 秒 | 中高 | 痛点共鸣 |
| 10-25 秒 | 中等 | 干货展开 |
| 25-35 秒 | 中高 | 反转/高潮 |
| 35-45 秒 | 高 | 结论/CTA |

> 节奏像心电图，不能一直平，更不能一直陡。

## 五、防流失 5 技巧

1. **声音牵引**：突然变调/插入音效/音乐切换
2. **画面牵引**：切镜头/放特写/转场特效
3. **文字牵引**：弹字幕/关键词高亮/数字跳动
4. **悬念牵引**："先别划走，最后这条最重要"
5. **互动牵引**："看到这里双击一下"、"评论区告诉我"

## 六、时长与完播率的反比关系

- 抖音 15s > 30s > 60s（完播率维度）
- 小红书 1min 笔记 > 3min > 5min
- B 站 8-15min 区间完播率最高
- 公众号 2000-3000 字阅读完成率最高

## ✅ 案例 vs ❌ 反例

**✅ 案例**：3 秒钩子 + 每 5 秒反转 + 30 秒总结 + "点个关注"收尾（完播率 78%）
**❌ 反例**：开头铺垫 30 秒 + 平铺直叙干货 + 无转折（完播率 12%）

## 🚀 30 秒应用

```text
[完播力自检]
1. 第 3 秒有钩子？ → 没有就重写
2. 第 8/15/25 秒有反转？ → 没有就加
3. 信息密度曲线是否起伏？ → 平就调整
4. 结尾有回环？ → 没有就补
5. 总时长匹配平台？ → 不匹配就剪
```
