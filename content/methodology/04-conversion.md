# 转化力方法论（Fire Score 维度 4 · 权重 20%）

> 转化力决定用户是否行动（关注/收藏/评论/加微信），是商业闭环的关键。

## 一、CTA 设计 4 要素

- **明确动作**：关注/收藏/评论/加群，不要用"欢迎..."
- **告知理由**：告诉用户行动后能获得什么
- **降低门槛**：强调"免费/1 步/3 秒"
- **制造稀缺**：限时/限量/限身份

**公式**：`[动作]+[理由]+[门槛]+[稀缺]`

## 二、5 类 CTA 模板

1. **关注型**："关注我，下期讲 [更干的干货]"
2. **收藏型**："先收藏，用的时候翻出来"
3. **评论型**："评论区扣 1，我私发你 [资料]"
4. **私域型**："主页加我，免费领 [清单 PDF]"
5. **裂变型**："转发到 3 个群，我拉你进 [高质量圈子]"

## 三、私域引流 4 路径

| 路径 | 风险 | 转化率 |
|------|------|--------|
| 主页签名 | 低 | 5-10% |
| 评论区互动 | 中 | 15-25% |
| 直播留资 | 中 | 20-35% |
| 资料包钩子 | 低 | 30-50% |

> 资料包钩子（"评论区扣 1 领"）是当下性价比最高的私域路径。

## 四、关注/收藏触发点

- **关注触发**：承诺系列内容 / 提供独家视角 / 强调持续更新
- **收藏触发**：信息密度高 / 工具属性 / 长尾价值
- **评论触发**：争议性观点 / 提问互动 / 晒图晒成绩

## 五、价值递进模型（AARRR 自媒体化）

```
曝光(Acquisition) → 关注(Activation) → 留存(Retention) →
推荐(Referral) → 变现(Revenue)
```

每个层级都对应不同的 CTA 设计：

- **曝光→关注**：钩子 + 承诺
- **关注→留存**：系列 + 稳定更新
- **留存→推荐**：转发钩子 + 社交货币
- **推荐→变现**：私域 + 资料包 + 直播

## 六、转化力红线

- 不要在每条内容都卖货（信任透支）
- 不要 CTA 太多（最多 1-2 个）
- 不要过早变现（新粉先养 7-30 天）
- 不要硬广（软植入 > 硬推）

## ✅ 案例 vs ❌ 反例

**✅ 案例**："看到这里的兄弟，双击一下，下期讲 [更干的]，评论区扣 1 领 [资料包]"（3 个 CTA 分层）
**❌ 反例**："喜欢的话记得点赞关注哦"（无理由、无门槛、无承诺）

## 🚀 30 秒应用

```text
[CTA 速写]
1. 选 1 个主 CTA → 关注/收藏/评论/私域
2. 套公式 → 动作+理由+门槛+稀缺
3. 放在视频 80% 进度位置 → 不要开头
4. 配 1 个引导动作 → 手指/箭头/字幕
5. 评论区置顶 → 配套福利钩子
```
