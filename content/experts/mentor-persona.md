# 学长型人设（Mentor Persona）

> 定位：从"过来人"视角分享实战经验，强调"我是怎么走过来的"

## 一、人设核心

- **身份**：同行业的学长/前辈
- **关系**：与观众是"师兄-师弟"平等关系
- **优势**：真实感强、信任度高、可复制路径

## 二、语言风格

| 维度 | 标准 |
|------|------|
| 称呼 | "兄弟们/家人们/小伙伴们" |
| 语气 | 平稳、语重心长、不夸张 |
| 节奏 | 中等偏慢，给观众消化时间 |
| 用词 | "我当年.../我当时.../后来我发现..." |
| 情感 | 真诚 > 激动，鼓励 > 打击 |

## 三、知识结构

- **基础盘**：行业基础认知、入门常见误区
- **进阶盘**：方法论、工具、案例
- **避坑盘**：亲身踩过的坑、可以绕开的弯路
- **趋势盘**：行业判断、机会识别

> 学长人设的核心是"路径可复制"，每条内容都应隐含"我走过的路 → 你也能走"。

## 四、10 个典型句式

1. `我当年 [踩过这个坑]...`
2. `如果让我重头再来，我会先做 [X]...`
3. `[X] 其实是 [Y] 行业的入场券`
4. `我花 [时间] 才明白的 1 件事`
5. `别再 [X] 了！我之前也是这样，后来...`
6. `[行业] 的真相是 [反常识]`
7. `我面试了 [数字] 个人，发现 [X]`
8. `新人最容易犯的 [数字] 个错误`
9. `我建议你 [具体动作]，因为 [原因]`
10. `[数字] 年后，我才看懂 [X]`

## 五、适用场景

✅ 适合：职场/职业规划/技能学习/创业复盘
✅ 强项：长期粉丝沉淀、高粘性
❌ 不适合：纯娱乐/搞笑/颜值类
❌ 弱项：短期爆发力弱

## 六、视觉呈现

- 背景：办公桌/书房/电脑屏幕前
- 穿着：商务休闲/理工感
- 镜头：中景/近景，稳定不晃动
- 字幕：工整清晰，不过度花哨

## ✅ 案例 vs ❌ 反例

**✅ 案例**："我做程序员 5 年了，今天想跟兄弟们聊聊新人最容易踩的 3 个坑"（真诚、平等、可复制）
**❌ 反例**："年薪百万的我来告诉你成功秘诀"（居高临下、不可复制）

## 🚀 30 秒应用

```text
[学长型脚本生成]
1. 开头 → "我当年..." 切入
2. 故事 → 1 个亲身经历
3. 干货 → 3 个可复制的动作
4. 结尾 → "希望你少走我走过的弯路"
5. 互动 → "评论区聊聊你踩过的坑"
```
