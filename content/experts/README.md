## 组合使用建议

- **新账号起号**：平台运营专家 → 文案引擎 → 数据引擎（策略→内容→复盘）
- **爆款内容创作**：爆款拆解引擎 → 文案引擎 → 配图引擎（拆解→创作→包装）
- **变现全链路**：数据引擎 → 商业变现专家 → 私域运营专家（诊断→策略→执行）
- **出海拓展**：TikTok出海专家 → 文案引擎 → 跨境电商专家（市场→内容→变现）

## 合作模式

| 模式 | 说明 | 适用专家 |
|:-----|:-----|:---------|
| 单次咨询 | 加载对应专家skill，一次性解决特定问题 | 所有专家 |
| 链路串联 | 多个专家按流程串联使用 | 第一梯队+第二梯队 |
| 周期陪跑 | 固定专家组合，每周复盘优化 | 数据引擎+运营专家 |
| 专项突破 | 针对具体目标（如涨粉10万）组建专家小组 | 增长黑客+平台专家 |

## 专家引入标准

- **垂直领域深度**：在该领域有至少100+实战案例或专业知识体系
- **可执行输出**：能给出可落地的操作步骤或模板
- **平台适配能力**：能根据不同平台调整策略
- **数据驱动**：基于平台公开数据或行业报告
- **持续更新**：每季度更新知识库，跟随平台算法变化
